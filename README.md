# Criminal Face Detection System

## 📌 Project Overview

The Criminal Face Detection System is a Java-based desktop application designed to manage criminal records and assist in identifying criminals using face detection technology. The system provides a user-friendly interface for storing, managing, and retrieving criminal information efficiently.

## 🚀 Features

* Secure Admin Login
* Add, Update, Delete Criminal Records
* Face Detection using OpenCV
* Criminal Database Management
* Real-time Camera Integration
* Alert Generation
* MySQL Database Connectivity
* User-Friendly Java Swing Interface

## 🛠️ Technologies Used

* Java
* Java Swing
* OpenCV
* MySQL
* JDBC
* NetBeans IDE

## 📂 Database Tables

* criminals
* alerts
* cameras
* reports
* monitoring
* students
* invigilators
* exams

## ⚙️ Installation Steps

1. Clone the repository.
2. Open the project in NetBeans IDE.
3. Import the MySQL database using `criminaldb.sql`.
4. Configure database credentials in the project.
5. Add OpenCV library.
6. Run the application.
